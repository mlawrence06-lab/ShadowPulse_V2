# Security Policy

## Supported Versions

Currently, only the latest version of the ShadowPulse Extension and Backend API are supported with security updates. We recommend all users to keep their extension updated to the newest release.

| Version | Supported          |
| ------- | ------------------ |
| v2.3.x  | :white_check_mark: |
| < 2.3.0 | :x:                |

## Reporting a Vulnerability

ShadowPulse takes security seriously. If you discover a security vulnerability within the ShadowPulse Extension or the `shadowpulse.live` API backend, please send an e-mail to **mlawrence06@gmail.com**.

**Please do not report security vulnerabilities through public GitHub issues.**

All security vulnerabilities will be promptly addressed. When reporting, please include:

- A description of the vulnerability and its potential impact.
- Steps required to reproduce the issue.
- Any potential mitigation or solutions you suggest.

You should receive a response within 48 hours acknowledging receipt of your vulnerability report.
